# Security reporting

[简体中文](docs/security.zh-CN.md)

Report fork-specific vulnerabilities privately to this repository's owner through GitHub private vulnerability reporting if the repository offers it. If unavailable, request a private reporting channel without posting exploit details or credentials publicly. Do not assume the upstream project's reporting form reaches this fork's owner.

Include the affected revision, deployment mode, minimal reproduction in an authorized environment, potential impact and sanitized diagnostics. Never upload live credentials, personal data or complete production backups.

For vulnerabilities also affecting unmodified AIHOT, the upstream [private reporting channel](https://github.com/KKKKhazix/AIHOT/security/advisories/new) is a separate appropriate destination. Keep unpublished exploit details out of public issues and PRs.
