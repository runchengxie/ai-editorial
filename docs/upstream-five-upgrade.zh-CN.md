# 五次上游提交的源码更新

[English](upstream-five-upgrade.md)

本次源码更新只合并 AIHOT 的 `fe46be3`、`04a3d42`、`0c6f287`、`7b446b1`、`4c6e9e1`。合并源码不代表安装生产版本、执行生产迁移、启用服务商或恢复发布。

继承的迁移 `0169_drop_selected_ledger_visible_at.sql` 会删除 `selected_ledger.visible_at` 及其依赖索引。该列原来与 `changed_at` 相同，新引擎已停止读写。SQL 注释中的批准只属于上游，不构成本项目生产库变更的授权。执行生产迁移前，必须另行取得所有者批准、检查依赖并保留已验证的备份。

新代码可以在删列前运行；旧代码仍引用该列，因此删列后不能只回退代码，应协调恢复数据库，或另行评审兼容方案。不要修改已发布的迁移来制造回退兼容。

SocialData 改用默认出口路径，模型输入中的过小图片会补边，正文清洗会删除明确标记的相关阅读区块。JSON 采集器从未实现 `rawDropKeys`，以前只允许配置该字段，现在会拒绝未知字段。校验或导入信源前应删除目录里的过时配置；这不会减少实际的数据过滤能力。
