# 依赖安全状态

[English](dependency-security.md)

截至2026年11月18日，npm最新picomatch为4.0.7。[官方公告](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)列明4.0.7及之前版本受影响，尚无修复版。Vite、tinyglobby和fdir的范围支持这一主版本，但不能选择尚未发布的修复。完整开发安装报告该依赖链5个高风险节点。自动修复建议会跨主版本倒退，因此没有降级、覆盖或屏蔽告警。

开发工具链风险仍未关闭。兼容补丁发布后，应在任务分支更新锁文件，再运行类型、构建、浏览器和发布检查。安装成功不能代替安全审计通过。

本机刊物安装器不安装开发依赖。独立归档安装证明，没有Vite和picomatch时生成模块仍可导入，生产依赖审计为0，CI也重复这一检查。这减少已安装任务的依赖暴露，不代表开发工具链公告已修复。独立静态阅读站在前次审计中也没有告警。
