# 编辑试用流程

[English](editorial-pilot.md)

先在内部运行，确认信源许可、凭据和预算后再启用真实采集与模型。进入 `/admin/editorial`，按标题、URL 或 ID 搜索已采集资料，选择读者方向后导入。采集仍在原有信源管理中配置，空数据库没有资料可供搜索。同一原始资料重复导入会打开已有选题。

1. 有用内容进入候选，开始制作时修改状态；放弃选题不会删除原始来源。
2. 打开原始链接，记录关键说法、限制条件和证据类型，再勾选已核对。日期缺失、来源变化或不可用会显示出来。
3. 保存证据后整理草稿。该功能组合已有说法与引用，不代表内容已经独立核实，也不生成模型润色的成稿。
4. 编辑选题角度、事实摘要和对读者的影响。待核实问题每行一条，解决后再清除；保存后才能确认审核。
5. 人工审核通过后，手动发布到外部平台，再填写链接并标记已发布。审核前也能导出，但会附带警示。导出仅包含已保存内容，不包含内部备注。
6. 出现新证据后重新打开选题。修改需要重新审核，历史快照会保留。保存冲突时保留输入，核对自己的修改后再主动重新加载。

## 建议的试用评估

先人工标注 100 条真实资料，覆盖金融研究和开发场景。资料与结果放在 DATA_ROOT/ai-editorial/evaluations/<明确的任务标识>/，记录引擎、模型和提示词版本、来源、时间及评估者。统计有用内容漏报、事件误合并、摘要中无依据的说法、编辑耗时、采用选题数和真实处理费用。不能用合成测试推断实际质量和成本。

目前尚未提供或校准试用语料和正式信源目录。可从上游示范信源开始，启用前逐一检查相关性和许可。保留出处，默认只展示摘要及原文链接。取得标注样本之前，不改变数字入选门槛。

推出会员订阅前，需要覆盖网页、订阅源、API、MCP 及缓存的完整权限设计与验证。现有匿名输出不具备会员访问控制。
