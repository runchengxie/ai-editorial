# 安全问题报告

[English](../SECURITY.md)

本分支的安全问题应私下联系仓库所有者。如果仓库提供GitHub私密漏洞报告入口，可通过该入口提交。若没有，请先请求私密报告渠道，不公开漏洞利用细节或凭据。上游的报告表单不会自动转交本分支所有者。

提供受影响版本、部署方式、在有权测试的环境中的最小复现、潜在影响及脱敏诊断信息。不上传真实凭据、个人数据或完整生产备份。

如果问题同时影响未经修改的AIHOT，可另行通过[上游私密报告渠道](https://github.com/KKKKhazix/AIHOT/security/advisories/new)反馈。未公开的利用细节不放在公开Issue或PR中。
