# 站点配置

[English](site.md)

`configs/site/` 是类型化的 `@aihot/site` 工作区，负责站点身份、品牌、动态应用文案与条款，以及启用模块的组合。参见[定制说明](customize.md)和[目录职责](repository-layout.zh-CN.md)。

| 路径 | 内容 |
| --- | --- |
| `site.ts` | 站点身份、界面文案、原动态报告时间及公开分类映射 |
| `models.ts` | 具名模型及引擎步骤的默认选择 |
| `brand/` | 图标、Logo、可选字标及联系图片、报告报头 |
| `pages/` | 运行时条款Markdown模板，公开使用前需所有者审核 |
| `public/` | 带可配置占位符的动态站点固定文件 |
| `changelog.json` | 动态站点更新日志 |
| `modules/` | 模块清单及服务端、网页组合，本分支已启用编辑工作台 |

动态引擎的时间或模型默认值不会启用独立刊物定时器或云端发布，刊物目前仍手动运行。模型凭据及生产设置保存在Git之外的CONFIG_ROOT。移动工作区不会改变npm包名，也不会更新已安装的不可变任务版本。
